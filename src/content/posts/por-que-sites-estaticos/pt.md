Nos últimos anos, a web passou por uma sobrecarga de abstrações. Bancos de dados relacionais para blogs simples, microsserviços para portfólios e frameworks pesados no cliente para páginas de leitura.

## A volta à sobriedade técnica

Manter um blog pessoal não deveria exigir atualizações de segurança de banco de dados, migração de tabelas ou gerenciamento de painéis de administração como o WordPress.

### O fluxo ideal do autor:
1. Abrir o editor de código no terminal.
2. Escrever um arquivo `.md` estruturado.
3. Visualizar instantaneamente com hot-reload local.
4. Executar `git push` para publicar.

> "A simplicidade é o último grau de sofisticação." — Leonardo da Vinci

Sem bancos de dados para falhar, sem servidores para gerenciar e sem surpresas no fim do mês.
